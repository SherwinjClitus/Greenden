## 🌱 About

**Greenden** is a responsive plant store website created using **HTML and Tailwind CSS**.

The website provides a clean and simple interface for browsing plants and exploring different sections of the store. The project focuses on practicing modern web design, responsive layouts, Tailwind CSS utility classes, and proper HTML structure.

---

## ✨ Features

- 🌿 Clean and modern plant-store design
- 🪴 Plant product showcase
- 📱 Fully responsive layout
- 🖥️ Desktop and mobile-friendly design
- 🧭 Simple navigation
- 🖼️ Responsive plant images
- 🎨 Tailwind CSS-based styling
- 📐 Flexbox and Grid layouts
- ✨ Hover effects and smooth transitions
- 🌐 Deployed using GitHub Pages

---

## 📄 Pages

### 🏠 Home

The homepage introduces the Greenden brand and showcases plants, featured products, and other sections of the website.

### 🛍️ Products

The products page displays plants in a clean and responsive grid layout along with their names and prices.

### 📞 Contact

The contact page provides a simple interface for users to get in touch.

---

## 🛠️ Tech Stack

- **HTML5** — Used to create the structure and content of the website.
- **Tailwind CSS** — Used for styling, layouts, spacing, typography, responsiveness, and hover effects.
- **Git & GitHub** — Used for version control and hosting the project.
- **GitHub Pages** — Used to deploy the live website.
