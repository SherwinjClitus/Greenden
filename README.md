## 📦 Installation

### Prerequisites
- Node.js (v14.0 or higher)
- npm or yarn
- [Any other prerequisites]

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/SherwinjClitus/Greenden.git
   cd Greenden
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Run the development server**
   ```bash
   npm start
   # or
   yarn start
   ```

5. **Open in browser**
   ```
   http://localhost:3000
   ```
